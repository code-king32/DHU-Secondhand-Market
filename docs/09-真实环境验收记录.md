### 2.5 交易链路 ✅

| 用例 | 结果 |
|------|------|
| 买家登录 | 200 |
| 买家 `POST /api/trades`（goodsId=1） | 201，status=PENDING |
| 卖家 `POST /api/trades/1/accept` | 200，status=ACCEPTED |
| 数据库 `market_trade` | buyer_id=2，seller_id=1，status=ACCEPTED |
| 数据库 `market_goods` | status 由 ON_SALE 变为 TRADING |

**结论：用户 → 商品 → 交易主链路在真实 MySQL 环境下全部打通。**

## 3. 发现的问题

| # | 问题 | 影响 | 处理建议 |
|---|------|------|----------|
| 1 | MySQL 服务 `MySQL97` 默认未自动启动 | 后端启动失败（无法连接 3306） | 开发文档注明启动步骤，或设为自动启动 |
| 2 | `application-local.properties` 未打进 jar | 首次以 jar 启动 + `--spring.profiles.active=local` 会报「找不到 DataSource」 | 部署文档注明：配置文件需放在运行目录，或改用环境变量 |
| 3 | 浏览器首次进入页面时 `/api/auth/me` 返回 401 | 属预期行为（未登录探测），非缺陷 | 可在前端静默处理，避免 console 报错 |

## 5. 复现步骤

```powershell
# 1. 启动 MySQL（管理员）
net start MySQL97

# 2. 初始化数据库（在仓库根目录）
mysql -u root -e "CREATE DATABASE IF NOT EXISTS dhu_secondhand DEFAULT CHARACTER SET utf8mb4;"
# 依次执行 sql/01~07 及 backend/src/main/resources/sql/runtime-schema.sql

# 3. 准备本地配置 backend/application-local.properties（数据库账号密码）

# 4. 启动后端
cd backend
java -jar target/secondhand-0.0.1-SNAPSHOT.jar --spring.profiles.active=local

# 5. 启动前端
cd frontend
npm install
npm run dev
# 访问 http://localhost:5173
```
